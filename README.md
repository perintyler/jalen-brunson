## Setup

```bash
barry install https://github.com/perintyler/jalen-brunson

barry pack jalen-brunson
```

## What it does

A great point guard manages the team. A great point guard elevates the players on the court. 

Swarms of agents can be a fickle bunch, but I can always rely on #11 to reset the floor and run a play to get us on track.

## The apps

- **iOS** — `point-guard-ios`, a phone client.
- **macOS** — `point-guard-macos`, a desktop client.
- **Web** — served by `point-guard` itself at `point.barry.rocks`.
